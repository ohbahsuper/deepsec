# Security policy

DeepSec est un outil défensif et passif. Utilisez-le uniquement avec une autorisation explicite, respectez les règles d’engagement et interrompez l’analyse si le propriétaire demande l’arrêt.

Pour signaler une vulnérabilité dans DeepSec, ouvrez un rapport privé auprès des mainteneurs lorsque cette fonction est disponible. N’incluez pas de secrets réels dans les issues publiques ; remplacez-les par des valeurs fictives et indiquez la version, le système et les étapes de reproduction minimales.
